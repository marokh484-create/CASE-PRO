## عن المشروع

**CASE-PRO** موقع تعليمي بالعربي بيشرح الكيسة وقطع الكمبيوتر بمجسمات ثلاثية الأبعاد تقدر تلفها وتقرّب منها. بتتعرف على كل قطعة جوه الكيسة، وبتتعلم تركيبها خطوة بخطوة، وبتجرّب التوافق بين القطع، وبتشوف مشاكل الكمبيوتر الشائعة وحلولها.

🔗 **جرّب الموقع:** https://marokh484-create.github.io/CASE-PRO/

## الأقسام

| القسم | بيعمل إيه |
|---|---|
| **استكشف** | مجسم 3D للتجميعة الكاملة، واختار أي قطعة (اللوحة الأم، كارت الشاشة، الرامات، التخزين، مروحة الكيسة، وحدة التغذية) وشوف وظيفتها ومكانها وأهم النصائح عنها. وفيه كمان قسم "الكيسة نفسها". |
| **الكيسة 3D** | لف الكيسة 360 درجة، وغيّر نوع الهيكل، و"فُكّ القطع" علشان تشوفها متفرّقة، واعرض مسار الهواء، وبدّل بين وضع التركيب ومعلومات القطع. |
| **تعلّم التركيب** | شرح تركيب الكيسة خطوة بخطوة، مع روابط فيديوهات شرح بالعربي والإنجليزي. |
| **مشاكل وحلولها** | مشاكل الهاردوير والسوفتوير الشائعة (شاشة، صوت، نت، سخونة، تجمد، ويندوز، هارد، رام، ألعاب، USB) مع بحث وحلول. |
| **جرّب التوافق** | معمل توافق: ركّب أي قطع على بعض وشوف النتيجة، مع مجسمات 3D، وإعداد متوافق، وإعداد فيه مشاكل، وإعداد عشوائي. |

## المميزات

- مجسمات 3D بتتحرك بالسحب، والتقريب بعجلة الماوس أو بإصبعين.
- وضع فاتح وداكن، والموقع بيفتكر اختيارك.
- **وضع الأداء (ON/OFF)** للأجهزة الضعيفة: بيقلل جودة المجسمات والظلال علشان الموقع يبقى أخف.
- شغال على الكمبيوتر والموبايل.
- بيشتغل من ملف HTML واحد من غير تثبيت أو build.

## التقنيات

- HTML و CSS و JavaScript من غير frameworks.
- [Three.js](https://threejs.org/) (r128) للمجسمات ثلاثية الأبعاد.
- خطوط Google Fonts: IBM Plex Sans Arabic و Reem Kufi.
- الاستضافة على GitHub Pages.

## تشغيل المشروع على جهازك

1. نزّل الـ repository أو انسخه: `git clone https://github.com/marokh484-create/CASE-PRO.git`
2. افتح ملف `index.html` في المتصفح.

محتاج اتصال بالإنترنت علشان مكتبة Three.js والخطوط بيتحمّلوا من الإنترنت.

## English

**CASE-PRO** is an Arabic, interactive educational guide to PC cases and components. It features rotatable 3D models of the case and its parts, an assembly guide, a troubleshooting section, and a component compatibility lab.

- **Live demo:** https://marokh484-create.github.io/CASE-PRO/
- **Features:** 3D case viewer with several case types, exploded view, airflow visualization, light/dark theme, and a Performance mode for low-end devices.
- **Stack:** plain HTML/CSS/JavaScript, [Three.js](https://threejs.org/) r128, hosted on GitHub Pages. No build step.
- **Run locally:** clone the repo and open `index.html` in a browser (an internet connection is needed for Three.js and fonts).
- **Contact:** marokh48@gmail.com
